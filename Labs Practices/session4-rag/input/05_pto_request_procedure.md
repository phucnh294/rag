# PTO Request Procedure

## Purpose

This procedure explains how employees submit, change, and cancel paid time off requests.

## Request Steps

1. Open the HR portal.
2. Select Time Away.
3. Choose the requested dates.
4. Select the appropriate leave category.
5. Submit the request to the manager.

## Approval

Approval depends on staffing, business deadlines, and existing team absences.

## Balance Display

The HR portal displays an employee's current available leave balance.

The displayed balance may differ from the employee's annual entitlement because of prior usage, carryover, adjustments, or future approved leave.

## Important

This procedure does not define how many paid leave days employees receive each year.
